# 视觉规范 v1.0.0

来源：已确认的系统蓝、深浅色和紧凑布局设计。`assets/theme.css` 为可执行样式真源；此规范是项目约定，不是对第三方设计标准的认证。

## 固定视觉

| 项目 | 浅色 | 深色 |
|---|---|---|
| 页面底色 | #f2f2f7 | #000000 |
| 卡片底色 | #ffffff | #1c1c1e |
| 控件底色 | rgba(120,120,128,.12) | rgba(120,120,128,.24) |
| 正文字色 | #000000 | #ffffff |
| 次要文字 | #6c6c70 | #98989d |
| 主色/折线 | #007aff | #0a84ff |
| 链接/重点值 | #0040dd | #409cff |
| 上涨 | #cf263d | #ff6472 |
| 下跌 | #158346 | #49cf84 |

红涨绿跌按数值方向，同时显示正负号。零变化用中性色；不能把“涨”自动解释为业务改善。多指标图颜色用于区分系列，不随日涨跌变色。错误/警告需文字说明，不能仅靠颜色。

字体顺序见 --font-ui：Apple 系统字体 → Helvetica Neue → 苹方 → Noto Sans SC → 微软雅黑 → sans-serif；不下载字体，不嵌入商业字体。不同系统的实际字体会不同，保持字号和层级即可。

页标题36px/650、区块标题21px/600、正文15px、核心数值36px/650、重点指标表17px、单位15px（卡片单位12px）、辅助说明12px、版本信息11px。数字使用 tabular-nums。移动端允许标题30px、卡片数字29px。不要把全部正文都加粗。

卡片圆角20px，摘要16px，选择器10px，主要按钮胶囊形。主卡片仅轻微阴影，蓝色用于主操作、选中项和重点值，不做大面积炫光。页面边距28px、窄屏16px；区块间距24px、网格间距14px，内部常用12/16/18/24px。

## 结构与密度

信息站中，外层只有一行站点导航，路径并入顶部；内层 HTML 一行操作栏约50px。窄屏可自然换行，不以极小字体硬挤。不要在嵌入 HTML 里复制外层目录、站点标题及历史版本栏。

业务数据截至/对比日期在业务操作栏；报表版本日期与文件下载在外层右下角，不冒充业务数据日。普通独立页可在文末右对齐显示版本信息；生成日期需另标。按用户需求增加日期筛选，不强加无用控件。

结论摘要、关键数字优先；表格按内容宽度排列，数字列对齐，名称与单位不拆字，轻分组底色+悬停高亮，不用拉宽名称列制造空白。超宽表在容器内横向滚动，整页不溢出。次要内容用默认折叠，具体模块由业务决定。

## 图表约定

迷你趋势用有效值 min/max 设纵轴（可上下约8%留白），不是强制从零开始；全部相等时给合理极小范围；无值显示“—”，单点显示点。扩展图应可查看实际数值、日期、单位和范围。不同卡片独立尺度不能直接比较斜率；标明“独立纵轴”。柱状图默认零基线。

缺失日期按有效日期展示，不伪造插值或零；若跨缺口连线需说明仅连接已有数据点。最新日期必须可见。重复日期/机构须先核对粒度。

“指标余额不能为负”不等于“增量占比不能为负”。年度新增贡献分子分母可负或接近零，占比可能为负/超过100%，需核对口径。异常值不得改成0或悄悄丢弃；如图上限制范围，提供“完整范围”和排除数量/原因，原始数据可查。真实份额按同口径分母计算，分母为0用缺失状态。

信息站大图优先使用注入的 echarts：可切换图例、dataZoom、提示框；模板的原生SVG只展示轻量无依赖方案。多指标与跨机构图的数值、单位、分母必须一致或明确分轴。
