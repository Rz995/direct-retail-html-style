# 交付前核验

- 内容：示例/真实数据清楚区分；没有遗留演示值、人员信息、环境专属ID或内部说明。无目标不凭空增加达成率。
- 视觉：实际打开最终HTML，核对深浅色、1280px桌面及375px窄屏。正文不被多层栏侵占；页脚不覆盖正文；表格只在自身容器滚动。
- 交互：主题切换、日期、详情开合、键盘焦点与Esc可用；无效控件删除，不做假筛选/假刷新。弹窗可关闭并回到触发点。
- 数据：两期可比、单位正确、最新日期可见；无值不为0，错误不当空结果；分母与分子同范围。异步请求防旧覆盖。
- 图表：迷你图按有效值范围，等值/空值/单点有正确状态；独立尺度提示；不静默隐藏异常；缺失不造数。
- Chrome81：基本样式不依赖flex gap、:has、color-mix、inset；不使用Array.at/structuredClone作为基础路径；弹窗用兼容实现或明确polyfill。不提供远端依赖作为唯一可运行路径。
