# 通用提示词（复制下方内容，补充末尾业务需求）

请用我提供的《直营 HTML 统一风格 v1.0》样板制作单文件 HTML。读取附件HTML里的CSS和组件；如同时提供skill包，以 assets/theme.css 和 references/visual-spec.md 为准。延续现有字体、系统蓝主色、浅灰页面底色、白色圆角卡片、深色模式、轻阴影和紧凑布局，不另创视觉风格。

固定视觉：系统字体，包含苹方/微软雅黑回退；标题36px、区块21px、正文15px、重点表格17px、核心数值36px；浅色主蓝#007aff、深色#0a84ff。数值涨红跌绿且带正负号，零变化中性；不要把涨跌自动解释为业务好坏。颜色、间距及圆角优先直接复用附件样式，避免复制多套独立定义。

根据我的业务内容选择结构，不必固定卡片数量、排行或侧边栏。结论和关键数字优先；正文紧凑可读，表格名称和数字不要隔很远，单位不拆字，支持悬停高亮。次要模块可默认折叠。顶部操作栏约50px，窄屏自然换行。在信息站里不重复制作外层目录/站点导航；业务数据截至与对比日期保留在业务操作栏，报表版本日期与下载放在外层右下角，独立HTML放文末右对齐。

如有趋势，迷你图用有效数据最小/最大值并适当留白，点击可展开大图；说明各图独立尺度，单点/等值/空值也能显示。最新日期明确可见，缺失日期不补0，不伪造插值；异常不能悄悄改值或删除。金额余额、年内增量与贡献占比要区分。多系列大图按需加入图例开关、日期缩放及提示框。

目标兼容Chrome81：flex间距用margin，避免依赖:has、color-mix、inset、Array.at、structuredClone和无兼容方案的dialog。单文件内联CSS/JS，不依赖公网字体/CDN。支持主题切换、键盘操作、窄屏及深浅色。普通离线页不用接信息站API；如需真实接入，先读另附的信息站接入规范并核对schema，不猜接口格式、日期、单位或报表ID。
