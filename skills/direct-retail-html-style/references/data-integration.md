# 可选数据接入

公开版skill只约定展示风格，不定义任何内部业务系统的接口、标识、数据结构或数据库实现。

用户要求实时数据时，先获取其目标平台正式接口文档及获授权的数据来源，确认登录方式、字段、单位、日期及错误处理。平台提供的脚本/图表库按正式文档使用，不猜测方法名称或查询格式。

普通离线HTML无需接入API。动态页面不内嵌访问令牌、密码或其他凭据；缺数据用缺失状态，接口失败不显示为零。每个区域展示实际数据日期，用户可手动刷新；日更数据不默认频繁刷新整页。

部署前验证本期/对比期范围、分页完整性、最新日期和异常状态。网络性能问题按目标平台文档处理，不绕过权限或平台限制。只有明确获得发布授权后才上传。
